## User Stories

### MVP Stories

**US-001: User Registration**
As a new user, I want to create an account using AWS Cognito so that I can securely access my personal recommendation list.

**US-002: User Login**
As a registered user, I want to log in using AWS Cognito so that I can view and manage my saved recommendations.

**US-003: Add Recommendation with TMDB Lookup**
As a user, I want to search for a movie or TV show by title using TMDB and select from results so that I can save it with accurate metadata (year, genre, poster).

**US-004: Manual Recommendation Entry**
As a user, I want to manually add a recommendation if it's not found in TMDB so that I can still track obscure or unreleased content.

**US-005: View All Recommendations**
As a user, I want to see a list of all my saved recommendations with posters and metadata so that I can browse what I've saved.

**US-006: Add Source Tag**
As a user, I want to assign a source tag (e.g., "Sarah", "NYT Podcast", "Instagram") to a recommendation so that I can remember who suggested it.

**US-007: Add Context Notes**
As a user, I want to include notes about why I'm interested so that I remember the context when choosing what to watch.

**US-008: Mark as Watched**
As a user, I want to mark a recommendation as watched so that I can keep my list focused on unwatched content.

**US-009: Delete Recommendation**
As a user, I want to delete recommendations I'm no longer interested in so that my list stays relevant.

**US-010: Edit Recommendation**
As a user, I want to edit the notes and source tag of a saved recommendation so that I can keep information current.

**US-011: User Logout**
As a logged-in user, I want to log out of my account so that I can ensure my information is secure when I'm done using the app.
